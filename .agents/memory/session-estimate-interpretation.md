---
name: Session estimate interpretation
description: Confirmed interpretation rules for calculating swimming-session duration from coach shorthand.
---

Recognize common unitless distances when paired with swimming notation, such as `400 IM`, `2 x 200 fc`, and compact forms like `200fc`. Do not require coaches to write `m`.

For complex sessions, turnaround intervals override pace calculations. A grouped `4x` block repeats all indented sets in that block, and optional `IF TIME` work is included in the displayed estimate unless a future product control explicitly excludes it.

**Why:** The user confirmed that this interpretation matched their manual estimate for a deliberately difficult real coaching session.

**How to apply:** Extend recognition conservatively so numbered coaching instructions such as `1: Fast BO` or `3 on each stroke` are not interpreted as distances.
